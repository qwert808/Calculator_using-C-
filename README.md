# 🧮 Arithmetic Calculator in C#

Hey folks! 👋  

This is a **fun project** – a simple yet powerful **Arithmetic Calculator** built using **C#**. 🎉  

## ✨ Features:
✅ Perform **Addition (+)**  
✅ Perform **Subtraction (-)**  
✅ Perform **Multiplication (×)**  
✅ Perform **Division (÷)**  

## 🚀 How to Use:
1️⃣ Run the program  
2️⃣ Enter two numbers  
3️⃣ Choose an operation  
4️⃣ Get the result instantly! 🎯  

## 🛠 Requirements:
- C# Compiler (.NET)
- Basic understanding of C# syntax

## 💡 Why This Project?
This is a beginner-friendly project to understand **basic C# operations** and improve coding skills. Perfect for learning and practice! 💻🔥
